# Premium Light UX Update

This version removes the dark/theme switch and keeps a clean light-only commercial style.

## Home changes
- Replaced information-heavy macro cards with four simple round progress rings:
  - Calories: fire symbol
  - Protein: chicken drumstick symbol
  - Carbs: grain symbol
  - Fats: avocado symbol
- Fixed date header so it shows Today only for the current date and shows the selected date for other dates.
- Made the date strip horizontally scrollable for smoother mobile use.
- Added BMI card on home.
- Added a simple 7-day calorie chart.
- Reduced visual noise by removing the commercial trust strip from the main dashboard.

## Nutrition view changes
- Added Food View / Nutri View segmented control.
- Food View shows meals grouped by Breakfast, Lunch, Dinner and Snacks.
- Nutri View shows calories, macros, fiber, sugar, sodium and extra micronutrient-style details such as potassium, vitamin A, vitamin C, calcium and iron.
- Micronutrient values are treated as estimates unless exact values come from a verified food source.

## Progress changes
- Rebuilt Progress page around useful charts:
  - Weekly consumed vs burned calories
  - Protein/carbs/fats stacked chart
  - BMI scale
  - Expenditure changes
  - Water and report/lab summary

## Navigation/theme changes
- Removed the theme toggle from desktop and mobile navigation.
- Bottom navigation now has five clear options: Home, Food, Progress, Groups, Profile.
