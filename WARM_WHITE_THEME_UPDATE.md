# Warm White Premium Theme Update

This build removes the green-heavy UI direction and moves Eatlyte to a warm-white premium style inspired by modern calorie/nutrition apps.

## Palette

- Background: warm white / cream
- Cards: white with soft cream borders
- Primary actions: charcoal black
- Accent: soft coral
- Carbs/energy accent: warm amber
- Fat/water/chart accent: muted blue
- Green is no longer used as the main theme color

## UI changes

- Warm white page background
- Charcoal primary CTA buttons
- Softer cards and shadows
- Bottom mobile navigation uses a floating premium pill
- Macro rings keep meaningful food colors but avoid green wash
- Landing page phone mockup and chart colors now match the warm theme
- Logo changed to a non-green premium mark
